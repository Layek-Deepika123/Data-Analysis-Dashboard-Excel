# Vrinda Store Sales Analysis Dashboard (MS Excel)
## Project Overview
The Vrinda Store Sales Analysis Dashboard is an interactive data analytics project built using Microsoft Excel.
The purpose of this project is to analyze annual sales performance for 2022 and generate actionable business insights to improve sales strategy for 2023–2024.
This project demonstrates skills in data cleaning, data analysis, visualization, and dashboard development using Excel.

# Business Objective
## Vrinda Store wanted to:
•	Understand customer purchasing behavior 
•	Identify top-performing regions and channels 
•	Analyze sales trends and order performance 
•	Improve marketing strategy using data-driven insights
